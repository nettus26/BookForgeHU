# BookForgeHU
BookForge HU - EPUB and DOCX book editor
# BookForge HU v1.0

Magyar EPUB és DOCX könyvszerkesztő alkalmazás.

## Technológia

- C#
- .NET 8
- WPF
- MVVM

## Modulok

- BookForge.App - felhasználói felület
- BookForge.Core - alapfunkciók
- BookForge.Epub - EPUB kezelés
- BookForge.Docx - DOCX kezelés
- BookForge.Services - szolgáltatások
- BookForge.Localization - magyar nyelvi erőforrások

## Cél

Egy modern, könnyen használható könyvszerkesztő létrehozása:

- EPUB import/export
- DOCX támogatás
- kattintható tartalomjegyzék
- metaadat kezelés
- könyvformázás

v1.0 fejlesztés alatt
